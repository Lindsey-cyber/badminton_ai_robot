# Historical HTML reports

These files were produced by a removed prototype report generator. Its demo branch generated synthetic shot and ball-speed values and a fixed inference-time number. Its video branch also used unvalidated heuristics, including assumed player height and arm-derived shuttle speed when no ball was detected. No labeled ground truth or Raspberry Pi measurement accompanies these HTML files.

Keep them only to inspect the early visualization concept. Do **not** cite their shot counts, physical speeds, accuracy or FPS as measured results. Current measurements live in the documented JSON benchmark reports; event output is explicitly named `ShotCandidate` until contact is validated.

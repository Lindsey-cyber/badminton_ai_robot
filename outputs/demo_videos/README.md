# Historical demo videos

`pose_demo.mp4` was generated from predefined player poses and shuttle positions, with simulated speed and FPS overlays. It is **not** camera footage or measured model output. The generator was removed so it cannot be mistaken for the real-time system demonstration.

Use the checked-in recording with `scripts/run_training.py` for real ONNX inference and a bounded pipeline. The recorded video still has no ground-truth shot labels and does not establish detection accuracy.
